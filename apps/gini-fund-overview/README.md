# Gini Capital Fund Overview

Interne Glance-app (384 px) voor de Gini-fondsen. Na elk fonds toont de band
de top 5 holdings: ticker, dagrendement en weging. Alleen voor het team.

Zie de map README in de indiening voor installatie (Toegangstoken =
GLANCE_ACCESS_TOKEN, schermcode led-groot of led-klein).
