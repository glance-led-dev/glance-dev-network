# Gini Capital Fund Ticker

Interne Glance-app (192 px) voor de Gini-fondsen. Na elk fonds toont de band
de top 5 holdings: ticker, dagrendement en weging. Alleen voor het team.

Zie de map README in de indiening voor installatie (Toegangstoken =
GLANCE_ACCESS_TOKEN, schermcode led-klein of led-groot).
