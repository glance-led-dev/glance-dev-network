# Now Serving

Now Serving shows what's being poured: a small "NOW SERVING" header with up to three bottle logos below it. One logo sits centered; more spread out with even gaps.

Logos get a bigger drawing when only one or two are showing.

## Configuration

- **Logo 1** through **Logo 3** — pick a brand from each dropdown, or None to leave the slot empty. Picking the same brand twice shows it once.
