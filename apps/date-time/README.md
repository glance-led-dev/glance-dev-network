# Date & Time — local date, time, and current weather for a US zip code.

Format: DATE | TIME | weather ICON + TEMP + CONDITION.

Each section has its own configurable color. The whole line shares one font
size/weight (small/medium/large, normal/bold) and only drops a size if the
full line — with real content — would overflow, so sizing stays consistent
instead of each section picking its own.
